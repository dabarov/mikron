Nothing of it is left in your browser. If it got in your way, the reason helps make it better for the next person.

What made you remove it?

Each choice opens a short form on GitHub with the reason filled in. You can add details there, or close it without sending.

It appeared when I did not want it It did not work on a site I use The measurements looked wrong I only needed it once Something else

Sending the form needs a GitHub account, and what you send there is public. This page itself sends nothing: no analytics, no cookies.

If it only got in the way sometimes

These settings are in the popup behind the Mikron toolbar icon.

  • It started while you were selecting text or using shortcutsChange the key from Shift to Alt, Ctrl or Cmd under "Hold to measure".
  • It clashed with one siteTurn off "Enabled on" for that site. Mikron stays on everywhere else.
  • You want it only now and thenAlt+Shift+M turns Mikron off and on. The toolbar icon shows OFF while it is off.
